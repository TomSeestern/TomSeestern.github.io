# Uses

## Editor + Terminal

I write most of my code in VS Code with the Vim extension. I've done stints with Neovim and IntelliJ, but VS Code hits the right balance between configurability and not spending a weekend tweaking a config file. The terminal is Ghostty on macOS and a plain Alacritty on Linux. Zsh with Starship prompt, because life is too short for a slow shell.

## Hardware

A MacBook Pro with the M4 Pro chip. It's the first laptop where I've never heard the fan, which still feels wrong. Attached to a 27-inch Dell 4K display when I'm at my desk. Keyboard is a Keychron K8 Pro with Gateron brown switches. Trackball is a Kensington SlimBlade, which everyone who visits my desk finds unsettling.

## Services

This site runs on Vercel with the free tier. GitHub hosts the repo and Actions handles CI. Resend delivers contact form emails. Domain is registered with Porkbun because they don't send me marketing emails every three days.

For the homelab: Proxmox as the hypervisor, NixOS for most VMs, AdGuard Home for DNS filtering, and Nextcloud for file sync. Grafana and InfluxDB handle monitoring, mostly so I can look at pretty dashboards and pretend the metrics are actionable.

## Desk Setup

Standing desk from FlexiSpot. An IKEA desk mat that cost eight euros and has outlasted three keyboards. Coffee is always within arm's reach, usually cold by the time I remember to drink it.
