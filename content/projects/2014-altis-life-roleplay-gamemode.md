From 2014 to 2016, I worked with friends on Altis Life, an Arma 3 roleplay gamemode. I was lead developer and project manager. We used SQF, SQL, Windows Server 2012, Arma 3, and TeamSpeak 3 to turn military simulation into a player-run world.

Early challenge was scale. More players meant more server pressure, more edge cases in custom mechanics, and more community work. We kept adding features, watching performance, collecting feedback, and updating game mode instead of treating launch as finish.

Project reached more than 300 concurrent players. That number was exciting, but it also made every bad decision visible. I learned to balance new ideas with stability and to treat player community as part of project, not audience sitting outside it.

Altis Life was first project where I had to lead both technical work and people. It taught me that roleplay systems only work when code, server performance, and clear shared rules hold together.
