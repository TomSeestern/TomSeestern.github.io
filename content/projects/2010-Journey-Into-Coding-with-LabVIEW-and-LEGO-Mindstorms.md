In late 2010, I joined an after-school program with LEGO Mindstorms NXT 1.0/2.0 kits and LabVIEW. I had no real programming background, so loops, branches, and error handling were not ideas I understood yet. They were blocks on a screen that sometimes made a robot move and sometimes made it sit still.

Each session followed same pattern. Build something, wire its behaviour in LabVIEW, run it, then find out why it did not do what I expected. Working with classmates helped because we could compare approaches instead of staring at one broken program alone.

Big moment was programming my first autonomous robot to navigate mazes. Watching a physical LEGO model follow instructions made programming feel much less abstract. It taught me that I learn fastest when I can test an idea, see result, and try again.

There is no repository or demo left from this project. What remains is memory of LabVIEW and an NXT kit showing me that software could control something outside screen.
