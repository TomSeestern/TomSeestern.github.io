In 2012, I moved from web technologies into C++ because I wanted to understand desktop applications. I was learning alone, working through small programs in C++ and later using Qt Creator. There was no product plan. Goal was to make things work and understand why they worked.

C++ was harder than visual LabVIEW. Memory management and object-oriented programming were not things I could solve by copying example code once. I kept building small exercises, breaking them, and returning to documentation and forums when I got stuck.

Those early desktop applications were small, but they mattered. Each one forced me to go beyond browser code and think about program structure, state, and what happens outside happy path.

Looking back, this was start of my longer C++ phase. Self-study gave me confidence to take on bigger desktop, robotics, and AI-related work later.
