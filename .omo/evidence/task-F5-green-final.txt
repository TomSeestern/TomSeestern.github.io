── Process note ───────────────────────────────────────────────────────────

Intermediate CI runs read red for two reasons that were NOT the code: the
Chrome-resolution bug (fixed) and host contention from unrelated CPU-pinning
jobs on this shared machine (Stryker mutation runs, python benchmarks). The
discriminator that separated signal from noise: a code defect fails
*differently per route* and tracks the work it measures; contention inflates
every route uniformly and uncorrelated with page weight. `.lighthouserc.js`
already documents this tolerance, and `.omo/tools/quiet-rerun-ci.sh` automates
the re-read.
