## Regression found and fixed (NOT a rewrite)

`responsive.spec.ts:104` "projects remains usable at mobile" was RED with
`scrollWidth=875 > clientWidth=375`. Proof it was T17-caused, not pre-existing:

    git stash push -- <the 6 T17 files>
    playwright test e2e/responsive.spec.ts --project=chromium --workers=1 --retries=0 -g "projects remains usable"
    -> EXIT=0, 3 passed   (HEAD = pre-T17)
    git stash pop

Root cause: the new flex header row (`title link` + `Selected` badge) left the
Flowbite `Card` as a grid item with `min-width: auto`; the `truncate` (nowrap)
`<h3>` set the grid track's min-content to the full title width, so the whole
`grid-cols-1` track expanded past the viewport. Minimal fix, one class:

    components/ProjectTeaser/ProjectTeaser.tsx
    - className="h-full w-full transition-colors ..."
    + className="h-full w-full min-w-0 transition-colors ..."

`min-w-0` lets the grid item shrink below min-content; the existing
`min-w-0` on the title `<Link>` + `truncate` then ellipsize correctly. No
markup, behavior, or feature change. Covered by the existing
`responsive.spec.ts` guard (R6.3 regression check already in place).
