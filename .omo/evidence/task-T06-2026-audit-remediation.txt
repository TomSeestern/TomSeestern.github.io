## Changes

### `lib/markdown.ts` — (+32 lines, 2 new exports)
- **`getMarkdownEntry(slug, dir)`**: Reads a single `.md` file at `process.cwd()/dir/slug.md`, parses with `gray-matter`, returns `GrayMatterFile<string> | null`. Returns `null` on any error (file missing, read failure). Eliminates the duplicated `fs.readFileSync` + `matter()` + try/catch pattern repeated 4× across both detail routes.
- **`getMarkdownSlugs(dir)`**: Lists `.md` filenames in a directory, strips extensions, returns `{ slug }[]`. Eliminates the duplicated `generateStaticParams` pattern across both routes.

### `app/blog/entry/[slug]/page.tsx` — (115 → 76 lines, -39)
- Replaced `fs`, `path`, `matter` imports with `getMarkdownEntry`, `getMarkdownSlugs` from `../../../../lib/markdown`.
- Page component: single `getMarkdownEntry()` call replaces try/catch block + null check.
- `generateStaticParams`: delegates to `getMarkdownSlugs("content/blog")`.
- `generateMetadata`: single `getMarkdownEntry()` call replaces try/catch block.
- Removed 13 lines of JSDoc on now-trivial functions.

### `app/projects/entry/[slug]/page.tsx` — (118 → 71 lines, -47)
- Same refactoring pattern as blog, using `"content/projects"` directory.
- Removed stale JSDoc referencing "Blog Post" in projects context.
