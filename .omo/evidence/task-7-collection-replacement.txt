## TL;DR

Replaced failed animated marquee with CSS-only responsive project collection.
Mobile uses native horizontal scroll-snap; desktop uses responsive grid. All
project cards render whole within collection bounds at 375px and 1280px in
light and dark themes. 43/43 E2E tests passed twice on isolated production
server.

## Root cause (previous marquee)

Continuously translated fixed-width duplicate tracks cross viewport boundaries
between cards. Opaque edge guards conceal fragments but cannot ensure underlying
title/body geometry is whole.

## Fix

- Mobile: `snap-x snap-mandatory` scroll container; each card is `w-screen`
  with `snap-start` and `shrink-0`. Native scroll obeys `prefers-reduced-motion`
  without custom animation.
- Desktop (`md:`): same list becomes `md:grid md:grid-cols-2 xl:grid-cols-3`
  with `md:w-full` and `md:min-w-0`.
- Removed: duplicate `.animate-marquee`/`.animate-marquee2` tracks, edge guards,
  `scroll-smooth`, dead Tailwind theme entries (`spacing.112`, `zIndex.marquee`,
  `animation.marquee`, `animation.marquee2`, keyframes).
- Preserved: Roman font system, Flowbite tokens, ProjectTeaser card semantics,
  real project links in normal tab order, CardMotionWrapper hover spring.
