## 2026-07-20 Chromium runtime restoration

### Root cause

`playwright.config.ts` requires no change. Playwright resolves the matching local
cache browser with `PLAYWRIGHT_BROWSERS_PATH="$HOME/.cache/ms-playwright"`:

```text
executablePath=/home/tom/.cache/ms-playwright/chromium-1228/chrome-linux64/chrome
```

Playwright launches its paired headless shell:

```text
/home/tom/.cache/ms-playwright/chromium_headless_shell-1228/chrome-headless-shell-linux64/chrome-headless-shell
```

`file` identifies that browser as a dynamically linked 64-bit ELF. Before the
configuration repair, `ldd` showed the actual first unresolved dependency:

```text
libglib-2.0.so.0 => /nix/store/vx2aqxs99ii6pkzndddnbrsqbc4jwpb6-glib-2.88.1/lib/libglib-2.0.so.0
libnspr4.so => not found
libnss3.so => not found
...
```

Minimal launch failed before navigation with exit 127:

```text
error while loading shared libraries: libnspr4.so: cannot open shared object file: No such file or directory
```

The prior `libglib-2.0.so.0` symptom was stale: GLib already resolved through
the Nix shell. `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` was also not selected by
Playwright's bundled executable resolution, so the stale-path hypothesis was
refuted. The real cause was `flake.nix` omitting several direct Chromium shared
libraries from `LD_LIBRARY_PATH`, including `nspr` and `nss`.

### Configuration remediation

`flake.nix` now adds Chromium's direct runtime closure to `chromeRuntimeLibs`:
`alsa-lib`, `cairo`, `cups`, `dbus`, `expat`, `fontconfig`, `freetype`, `gtk3`,
`libdrm`, `libGL`, `libx11`, `libxcb`, `libxext`, `libxkbcommon`, `nspr`,
`nss`, and `pango`, alongside existing dependencies. This source configuration
change was necessary because runtime evidence showed an incomplete Nix library
path; no application, route, typography, component, or test source changed.

Minimal browser proof after `nix develop` rebuilt the shell:

```text
ldd "$HOME/.cache/ms-playwright/chromium_headless_shell-1228/chrome-headless-shell-linux64/chrome-headless-shell" | grep "not found"
# no output
executablePath=/home/tom/.cache/ms-playwright/chromium-1228/chrome-linux64/chrome
launch=ok
```
