## Normalization design

- **Key** = raw tag trimmed, `_`/`-` runs folded to a single space, whitespace collapsed, lowercased.
- **Label** = most frequent original raw form; ties broken case-insensitively then by code-unit for order independence.
- **Slug** = lowercase, `+` → `-plus`, every run outside `[a-z0-9]` → single `-`, trimmed.
  `C++` → `c-plus-plus`, `Arma 3` → `arma-3`, `AWS-Amplify` → `aws-amplify`, `NodeJS` → `nodejs`.
- **Collision assertion** = two distinct keys slugging to the same value THROWS naming both keys (build fails loudly rather than silently merging).

## Regression found and fixed in the same commit

Adding the 7th footer link (`/tags`) to the non-wrapping
`flex items-center justify-center space-x-1` row overflowed it at the 375 px viewport; with
no `shrink-0`, flexbox crushed the four social/email icon anchors from 32×32 to **16×32**,
below the WCAG 2.2 24 px floor, failing `e2e/responsive.spec.ts` touch-target tests on
`/`, `/blog`, `/contact`.

**Proven causal:** stashing only the 6-line Tags addition made the 3 tests pass
(`3 passed (26.5s)`); restoring it made them fail. **Fix:**
`flex flex-wrap items-center justify-center gap-1` + `shrink-0` on all 7 anchors.
No test was weakened, no `MIN_WCAG_TARGET_SIZE_PX` change, no budget change.
Post-fix: focused touch-target run `3 passed`; full suite `83 passed`.
