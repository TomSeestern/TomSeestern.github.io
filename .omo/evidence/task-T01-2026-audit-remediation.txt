=== DESIGN DECISIONS ===
- Script placed inside <body> as first child (not <head>, not direct <html> child):
  * <head>: Next.js strips custom <head> wrapper in App Router root layout
  * Direct <html> child: React hydration error "In HTML, <script> cannot be a child of <html>"
  * Inside <body>: Valid HTML5, browser stops parsing at <script>, executes synchronously
- SSR default is dark class (not light): inline script fixes before paint for light-preferring users
- localStorage write on first visit: DarkThemeToggle's useThemeMode defaults to "light" when no localStorage found, which would remove the SSR "dark" class. Writing localStorage during init prevents this race.
- addInitScript used in e2e instead of emulateMedia alone: emulateMedia's colorScheme does not propagate to synchronous inline script's matchMedia check. addInitScript sets localStorage before page load.
- RSC fetch errors filtered: "Failed to fetch RSC payload" errors occur in next dev headless tests but are benign (fallback to browser navigation works)

=== SCRIPT EXACT CONTENT ===
(function() {
  try {
    var mode = localStorage.getItem("flowbite-theme-mode");
    if (mode === "dark") {
      document.documentElement.classList.add("dark");
    } else if (mode === "light") {
      document.documentElement.classList.remove("dark");
    } else if (window.matchMedia("(prefers-color-scheme: dark)").matches) {
      document.documentElement.classList.add("dark");
      localStorage.setItem("flowbite-theme-mode", "dark");
    } else {
      document.documentElement.classList.remove("dark");
      localStorage.setItem("flowbite-theme-mode", "light");
    }
  } catch (e) {}
})();
