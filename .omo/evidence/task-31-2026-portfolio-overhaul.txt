# Task 31 — Responsive design audit
## Date: 2026-07-20
## Model: 9router/default

### Scope
- Audited `/`, `/about`, `/blog`, discovered blog detail, `/projects`, discovered project detail, and `/contact`.
- Viewports: 375×812, 768×1024, 1280×960.
- Added responsive E2E coverage and fixed browser-confirmed mobile overflow only.

### Browser-confirmed defect and fix
- At 375px, `/blog` expanded document width to 1033px. Geometry identified the Flowbite article card and descendants as overflow sources.
- `components/ArticleTeaser/ArticleTeaser.tsx`: added `min-w-0` to the Card root. This permits the grid item to shrink within the mobile content width.
- `/` marquee elements extend beyond viewport while moving, but enclosing marquee region has local `overflow-hidden`; after the card fix document width remains within viewport. No global overflow suppression added.
