Fixes (one commit each, R39.5):

  4bb32fd  perf(projects): lazy-load below-fold tech icons
           ProjectTeaser emitted 89 <img> with no `loading`, so Next
           auto-injected one `rel="preload" as="image"` per icon — 58
           preloads / ~140 KB on /projects, 0 on every other route.
           Fix: `loading="lazy" decoding="async"`.
           Deterministic proof: projects.html preload count 58 -> 0
           (fresh production build, `.next/server/app/projects.html`).
           Regression lock: ProjectTeaser.test.tsx added a test asserting
           both attributes; verified it FAILS without the change and PASSES
           with it (R16.6). Full suite 163/163 pass.

  af374b7  perf(blog): right-size cheesecake recipe photo
           93,924 B (1024x608) -> 43,576 B (768x456) WebP q78, -53.6 %.
           768 px covers mobile 2x DPR (380 CSS -> 760 device) and desktop
           1x (720 CSS). Aspect ratio preserved (1.684). PSNR 35.3 dB.
           `pnpm images` PASS (limit 200 KB).

  34fac22  perf(css): scope Tailwind content scan to the imported Card
           Content glob `node_modules/flowbite-react/**/*` ->
           `.../dist/components/Card/*.{js,cjs}`.
           Stylesheet 136,640 B -> 61,034 B (-55 %).
           Safety proof (the risk: dropping a used class):
             - selector-set diff across all 119 pre-rendered HTML docs:
               0 dropped selectors that appear in markup.
             - every Card theme class retained, incl. escaped dark variants
               (.dark\:bg-gray-800, .dark\:border-gray-700).
           This shortens the critical path shared by EVERY route.
