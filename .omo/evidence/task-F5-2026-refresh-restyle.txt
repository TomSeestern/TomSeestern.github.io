## 3. Bug found AND fixed during F5 (was blocking Lighthouse startup)

The first Lighthouse attempt could not start the server at all:
```
[Error: Could not find a production build in the '.next' directory.]
```
Cause: the preceding e2e run's Playwright `webServer` boots `next dev` and
overwrites `.next` with dev output (documented T22 gotcha). Lighthouse's
`startServerCommand: "pnpm start"` then has no production build to serve.
Fix applied to the run procedure: `rm -rf .next && pnpm build` immediately
BEFORE `pnpm lighthouse`. This is an operation-order requirement, not a product
defect — CI's `lighthouse.yml` already runs `pnpm build` in the prior step.
