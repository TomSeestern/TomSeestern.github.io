## 3. axe spec results

File: `e2e/a11y.spec.ts`; allowlist: `e2e/fixtures/a11y-known-violations.ts`.

```
nix develop -c bash -c 'unset PNPM_HOME npm_config_prefix; \
  export PLAYWRIGHT_BROWSERS_PATH=$HOME/.cache/ms-playwright; \
  pnpm exec playwright test e2e/a11y.spec.ts --project=chromium --reporter=list'
A11Y_EXIT=0
  15 passed (23.5s)
```

Coverage: 7 routes x 2 schemes (light/dark) = 14 route scans + 1 allowlist
integrity test. Only `serious`/`critical` axe impacts fail the run.

Seeded allowlist (matches T02 baseline once the marquee animation is frozen):

| route | scheme | rule | nodes |
|---|---|---|---|
| `/` | dark | color-contrast | 9 |
| `/blog` | dark | color-contrast | 6 |
| `/projects` | dark | color-contrast | 21 |
| `/about` | light | color-contrast | 2 |

Determinism fix: the home projects marquee is an infinite CSS animation; which
cards are visible at scan time varies, so `color-contrast` node counts flapped
(9 vs 10) under parallel load. The spec emulates `prefers-reduced-motion:
reduce`, which the marquee already honours (`motion-reduce:animate-none`,
`app/page.tsx:111`), freezing the layout. After that, 6/6 repeated parallel
scans of `/` dark returned exactly 9.

```

  pnpm e2e:headless --project=chromium'
CI_E2E_EXIT=0
  55 passed (1.6m)
```

Unqualified `pnpm e2e:headless` (all three browser projects) is **not** usable in
this devShell and was already so before T04: `flake.nix` installs only
`chromeRuntimeLibs` (`flake.nix:24`), so firefox/webkit fail at launch with
`Host system is missing dependencies`. Proven pre-existing on an untouched spec:

```
$ ... pnpm exec playwright test e2e/home.spec.ts --project=firefox
Error: browserType.launch: Host system is missing dependencies to run browsers.
Missing libraries: libstdc++.so.6 libXcursor.so.1 libXi.so.6 libgdk_pixbuf-2.0.so.0 libXrender.so.1
1 failed
```

Also, the unqualified chromium run with the default 11 workers has a
pre-existing dev-server flake (`page.goto` timeout in `dark-mode.spec.ts`)
unrelated to this task — removing the a11y spec entirely still produced
4 failed / 33 passed:

```
$ ... playwright test --project=chromium --grep-invert "accessibility"
```

The CI-equivalent `CI=true` run (workers=1, retries=2) is green (55 passed).
