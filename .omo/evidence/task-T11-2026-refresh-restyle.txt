10. RISKS / NOTES
================================================================
- A single shared Provider also shares skipDelayDuration (Radix default 300ms):
  moving between two different technology icons within 300ms now opens the
  second instantly, whereas previously each icon owned a fresh provider (200ms
  every time, same-icon re-hover was already instant). This is the intended
  benefit of a single root provider and does not change copy, position, side,
  or the 200ms delayed-open path (asserted in e2e).
- All production tooltip triggers are decorative <img>/<span>; they are not
  keyboard-focusable, so browser-level focus coverage is impossible without
  changing interaction semantics (out of scope). Keyboard focus behavior is
  covered by the Jest test "reveals explanation when trigger receives keyboard
  focus". Pre-existing condition, not introduced by T11.
