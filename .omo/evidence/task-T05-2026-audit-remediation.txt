- Added Zod schema `contactFormSchema` with `name`, `email`, `message` fields
- Typed return: `SendEmailResult = { success: true } | { success: false; errors: Record<string, string> }`

## Edge cases covered
- Empty string passed as name, email, message → Zod `.min(1)` catches
- Non-email string in email field → Zod `.email()` catches
- Resend API throws → caught by `await-to-js`, returned as `_form` error (no stack leak)
- Missing `RESEND_API_KEY` env var → `_form` error, no Resend call attempted
- Rate limit exceeded → 6th call in 15-min window returns `_form` error
- IP header absent → falls back to `127.0.0.1` (documented in code)
- `headers()` throws outside request context → caught by try/catch

## Detractions
- Rate limiter is per-instance only; documented in code with recommendation for Redis/Upstash at scale
- No persistent storage for rate-limit state across deployments
